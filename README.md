# RecycleTrack

RecycleTrack is a mobile application designed to help users track and improve their recycling habits. It features barcode scanning for waste identification, location-based recycling center discovery, and a rewards system to encourage sustainable practices.

## 🚀 Project Status

This project is currently in **Alpha development**. Below is an overview of completed, ongoing, and planned features.

### ✅ Implemented Features
- Basic app navigation structure
- Camera access and permissions
- Initial UI components
- Tab-based navigation
- Home screen with a scan button

### 🔨 In Progress
- Barcode scanning functionality
- Camera autofocus and optimization
- Error handling for camera operations

### 📋 Planned Features
- Product recycling database integration
- Map integration for nearby recycling centers
- Rewards system for sustainable habits
- User authentication
- Social sharing capabilities
- Community features
- Environmental impact tracking

## 🏗 Getting Started

### Prerequisites

Ensure you have the following installed:
- Node.js (v14 or later)
- npm or yarn
- Expo CLI
- iOS/Android device or emulator

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Shreyanshdiwakar/Recycle-Track.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Recycle-Track
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npx expo start
   ```
